# storefronts: sources
Lettering masks, room back walls and cut-outs are drawn at load on a canvas by `game/src/streets/storefronts.art.js`; all geometry is
generated in `storefronts.js`. Shop names are invented and generic (no real brands, logos or trade dress); fonts are whatever system
faces the browser has (text only, nothing shipped).

Detail textures in `tex/` (1024 px JPG, colour + OpenGL normal), copied unchanged from `../../../../../../assets-scout/` (the asset scout's cut-down copies):
